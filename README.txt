WCT Hoops website

TO PUBLISH: in Netlify choose the "deploy manually" (drag and drop) option and drop THIS whole folder in.
The site starts at index.html. Do not drop the zip file itself, drop the unzipped folder.

TO EDIT:
- Text and prices: open the .html files (shop.html for merch, coaches.html, alumni.html) in any text editor.
- Order/contact email: one line near the top of the shop section in assets/js/main.js (SHOP_EMAIL).
- Photos: assets/img  (keep the same file names, or update the name in the .html file)
- Colours and fonts: assets/css/style.css

BEFORE EDITING: copy the whole folder as a backup.

TO DO BEFORE LAUNCH: the Instagram / TikTok / Facebook icons still link to "#". Replace each href="#" with the real link.
The contact form only works once the site is on Netlify (turn on Forms > form detection, and add a notification email).
